Network Security Basics Lab

Overview

This project was completed as part of a cybersecurity internship program. The objective was to build a foundational understanding of network security concepts, identify common network threats, configure basic security controls, and analyze network traffic using Wireshark.

Internship Task

As part of the internship, I:

* Studied common network threats and attack vectors.
* Configured basic firewall security controls.
* Captured and analyzed network traffic using Wireshark.
* Documented findings and recommended security best practices.
